我要在本文件夹下创建一个类似钉钉审批流的编辑器，使用 div span button等元素构成。我将系统功能进行以下说明：
1。编辑器支持 开始，结束，动作，分支这些类型的节点。一个配置必有一个开始节点和一个结束节点，其他节点可以添加任意数量
2。开始，结束，动作这3种节点样子只要渲染成不同颜色的矩形即可
3。分支类型是复合性节点组，默认有左右两个分支，分支上带有一个框，写着分支条件
4。分支类型可以增加分支，也可以删除分支。当删除其中某一条分支时，这条分支上所有的配置都要删除。如果某个分支配置删除完分支以后只剩最后一条分支了，则整个分支组全部删除
5。开始，动作节点后要跟添加下一个节点按钮，分支组内的分支上，以及最后分支合并输出后也要跟一个添加按钮
6。分支组内的分支上可以添加动作，也可以继续嵌套分支组，也就是说分支需要支持递归
7。节点采用从上往下去布局
8。节点间的连线使用 css 实现，千万不要用svg 等单独绘制，而是多借助于 before after border 等来实现
9。我有一个基本的设计，还不够完善：
开始，动作节点组件包含本节点的元素加下一步按钮，这样节点与按钮之间的连线可以通过在下一步按钮上添加before 和 after 实现
结束节点通过在自己的元素上使用before添加前面的线，用来说明跟前面节点的连接
分支节点组，每个分支上有一个分支节点名称组件，由名称框和后面跟一个添加按钮构成组件。
分支组内的分支上的的节点可以看做是一个节点组，即使这个分支上就一个分支名+下一步按钮的组合，这样分支与分支之间按照flex + gap 的水平布局，能比较方便的实现分支上平铺
10。代码编写过程中，你可以使用 playwright 这类的无头浏览器去跑单元测试，发现问题，改正问题
