// SUMMARY - How it works

1. _onDragStart:
   - Initializes drag operation
   - Sets up event listeners for move/end
   - Clears text selection

2. _onDragOver (called repeatedly during drag):
   - Calculates if element can be dropped at current position
   - Finds nearest draggable/sortable element
   - Determines insertion point based on mouse position
   - Emits dragOver/dragOverValid events
   - Performs visual reordering (DOM manipulation)

3. _onDrop:
   - Finalizes the drag operation
   - Calculates old vs new positions
   - Emits drop/dragend events
   - Triggers state updates

4. Key Flow:
   DragStart -> [DragOver (multiple times)] -> Drop
                    |
                    +--> Check position
                    +--> Find nearest element
                    +--> Insert at calculated position
