# 节点和连线的规则

## 已实现规则 ✅

### 数据输入节点 (in-node)
- [x] 数据输入节点只能连接到别的节点，不能由别的节点连接到它
- [x] 只有输出锚点（右侧），没有输入锚点

### 数据输出节点 (out-node)
- [x] 数据输出节点只能由别的节点连接到它，它不能连接到别的节点
- [x] 整个画布中只能有一个数据输出节点，拖入多个输出节点时提示"画布中只能有一个数据输出节点"
- [x] 数据输出节点只能由一个前置节点连接到它，不能由多个前置节点连接到它
- [x] 只有输入锚点（左侧），没有输出锚点

### 单输入节点 (where-node, field-node, group-node, distinct-node)
- [x] 图中所有节点都是由左侧锚点输入，右侧锚点输出
- [x] 只允许有一条边连接到它（单输入限制），后续再连接时提示"节点输入连线超出限制"

### 双输入节点 (join-node)
- [x] 图中所有节点都是由左侧锚点输入，右侧锚点输出
- [x] 最多只能有两个前置节点连接（左表、右表），超出后提示"横向连接节点最多只能有两个前置节点连接"

### 多输入节点 (union-node)
- [x] 图中所有节点都是由左侧锚点输入，右侧锚点输出
- [ ] 允许多个前置节点连接（UNION需要多个表）

### 所有锚点
- [x] 左侧输入锚点不能往外连接边（edgeAddable: false）
- [x] 右侧输出锚点可以往外连接边

## 实现位置

| 规则 | 实现位置 | 说明 |
|-----|---------|------|
| 数据输入节点只能连出 | SqlNodeModel.ts sourceRules | 无需额外限制，因为只有输出锚点 |
| 数据输入节点不能作为目标 | SqlNodeModel.ts targetRules | 规则5: in-node 返回 false |
| 数据输出节点不能连出 | SqlNodeModel.ts sourceRules | 规则2: out-node 返回 false |
| 数据输出节点只能单输入 | SqlNodeModel.ts targetRules | 规则6: 检查 incoming.length === 0 |
| 数据输出节点只能有一个 | editor.vue handleDrop | hasNodeType("out-node") 检查 |
| where/field/group/distinct 单输入限制 | SqlNodeModel.ts targetRules | 规则7: 检查 incoming.length === 0 |
| join-node 最多2条输入 | SqlNodeModel.ts targetRules | 规则8: 检查 incoming.length < 2 |
| union-node 多输入（不限制） | SqlNodeModel.ts targetRules | 不在限制列表中 |
| 锚点方向控制 | SqlNodeModel.ts getDefaultAnchor | in-node [out], out-node [in], 其他 [in, out] |
| 左侧锚点不能拖出 | SqlNodeModel.ts getDefaultAnchor | edgeAddable: false |

## 数据结构

```typescript
// NodeType 定义
interface NodeType {
  type: string;        // 节点类型
  name: string;        // 节点显示名称（中文）
  title: string;       // 节点标题（可编辑，当前同 name）
  color: string;       // 节点颜色
  icon: string;        // 图标名称
  anchors: {
    in: boolean;       // 是否有输入锚点
    out: boolean;      // 是否有输出锚点
  };
  defaultConfig: {
    width: number;     // 节点宽度
    height: number;    // 节点高度
  };
}
```

## 节点类型列表

| 类型 | 名称 | 锚点配置 | 输入限制 |
|-----|------|---------|---------|
| in-node | 数据输入 | 只有输出 | - |
| out-node | 数据输出 | 只有输入 | 只能有一个前置节点 |
| where-node | 数据筛选 | 输入+输出 | 单输入 |
| field-node | 字段设置 | 输入+输出 | 单输入 |
| group-node | 分组汇总 | 输入+输出 | 单输入 |
| distinct-node | 去重 | 输入+输出 | 单输入 |
| join-node | 横向连接 | 输入+输出 | **最多2条输入**（左表、右表） |
| union-node | 追加合并 | 输入+输出 | 多输入（不限制） |
